# WorkSphere - Freelancer Job Portal

WorkSphere is a web-based Freelancer Job Portal developed using Flask and SQLite. The platform connects clients and freelancers, allowing users to post jobs, apply for projects, and manage their professional profiles.

## Features

### Client Features
- User Registration and Login
- Create and Manage Job Posts
- View Freelancer Profiles
- Manage Job Applications

### Freelancer Features
- User Registration and Login
- Create Professional Profile
- Browse Available Jobs
- Apply for Projects
- Track Application Status

### General Features
- Secure Authentication
- Responsive User Interface
- Profile Management
- Database Integration
- Dashboard for Users

## Technology Stack

- Flask
- SQLite
- HTML

- JavaScript

## Installation

1. Clone the repository

```bash
git clone https://github.com/AMR3939/WORKSPHERE-FREELANCER-JOB-PORTAL.git
```

2. Navigate to the project folder

```bash
cd WORKSPHERE-FREELANCER-JOB-PORTAL
```

3. Install dependencies

```bash
pip install -r requirements.txt
```

4. Run the application

```bash
python app.py
```

5. Open in browser

```
http://127.0.0.1:5000
```
